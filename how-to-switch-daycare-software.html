How to switch to daycare software without a long migration

Most centres do not need a six-month project. Start on Free, run one classroom in parallel with paper for a week, then invite parents when teachers are comfortable.

Start free Leaving paper?
Four steps

A practical switch path

1. Start free

Create your centre in the browser — no credit card. Free includes core classroom tools with published limits. What Free includes.

2. Install Admin

Log in with the same email. Add one location and one class first — do not import your whole history on day one.

3. Teacher trial week

Have one teacher log meals, naps, and attendance in the Teacher app while paper stays as backup. Attendance software overview.

4. Invite parents

Send invitation codes when the room is steady. Families see updates in the Parent app — not a public marketplace. Parent communication.

Coming from another product?

What to expect

No automatic import

We do not pull Brightwheel or Lillio data automatically. Re-enter the active roster — it is usually faster than a broken migration for a small centre.

Keep paid tools for later

Vault, billing tracking, and licensing visit export are on Paid. Start Free for the classroom day, then upgrade when you need compliance tools. Licensing visit prep.

Canada-hosted records

Production centre data is stored in Canada. See Security and Daycare software for Canada.
